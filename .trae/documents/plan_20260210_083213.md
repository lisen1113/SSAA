- 表格有边框、居中对齐、自动换行

- 页边距为 12px，行高为 1.3
- 报价有效期为 7 天
- 报价单编号使用 quoteNumber 变量

- 没有详细的样式设置
- 报价有效期为 30 天
- 报价单编号硬编码生成

## 修复方案

1. **更新 HTML 结构**：使用与导航菜单相同的完整 HTML 结构
2. **统一样式设置**：应用相同的 CSS 样式，包括字体、大小、边距、行高等
3. **统一数据处理**：确保报价有效期为 7 天，报价单编号使用 quoteNumber 变量
4. **统一表格样式**：确保表格有边框、居中对齐、自动换行等效果
5. **统一导出流程**：保持与导航菜单相同的导出流程和用户提示
