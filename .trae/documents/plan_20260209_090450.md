# 报价单计算逻辑优化方案

## 问题分析

用户反馈：报价单摘要中，不含税金额和折扣没有关系，不用重复计算。只根据小计金额计算即可。

分析当前代码：

1. **当前计算流程**：
   - 遍历产品项，计算每个产品的折扣后金额（小计）
   - 汇总所有产品的小计金额
   - 计算不含税金额：小计金额 / 1.13
   - 计算税额：不含税金额 × 13%
   - 计算价税合计：不含税金额 + 税额

2. **存在的问题**：
   - 计算了 `totalDiscount` 变量，但该变量未被使用
   - 代码逻辑可能导致误解，让用户认为折扣在不含税金额计算中被重复考虑
   - 计算过程包含不必要的步骤

## 解决方案

### 1. 简化计算逻辑

* **删除未使用的折扣计算**：移除 `totalDiscount` 变量和相关计算
* **保持核心计算**：只计算产品项的折扣后金额和总小计
* **确保计算准确性**：不含税金额 = 总小计 / 1.13，税额 = 不含税金额 × 13%

### 2. 代码修改

修改 `updateQuoteTotals()` 函数：

1. 移除 `totalDiscount` 变量的声明和计算
2. 简化产品项遍历逻辑，只计算必要的折扣后金额
3. 保持不含税金额、税额和价税合计的计算逻辑不变

### 3. 实现步骤

1. 修改 `updateQuoteTotals()` 函数，移除未使用的 `totalDiscount` 变量
2. 简化循环逻辑，只计算折扣后金额和总小计
3. 保持不含税金额、税额和价税合计的计算逻辑不变
4. 测试验证所有功能正常工作

## 预期结果

* 代码逻辑更加清晰，避免用户误解
* 计算过程更加高效，移除不必要的计算步骤
* 保持计算结果的准确性
* 所有导出功能（Excel、PDF、Word）仍然正常工作
