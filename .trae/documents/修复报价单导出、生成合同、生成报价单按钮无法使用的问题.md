## 问题分析

在之前的修改中，我们将报价单中产品项的“数量”从静态div改为了可编辑的输入字段（带有`item-quantity`类）。但是，`collectQuoteData`函数（用于收集报价数据，供导出、生成合同、生成报价单等功能使用）仍然在尝试从静态div中获取数量：

```javascript
const quantity = item.querySelector('td:nth-child(4) div').textContent;
```

当函数尝试执行这一行代码时，它会找不到对应的div元素，从而导致函数失败，进而使导出、生成合同、生成报价单这些按钮无法使用。

## 修复方案

修改`collectQuoteData`函数，使其优先从`item-quantity`输入字段中获取数量，类似于我们在`updateQuoteTotals`函数和折扣事件监听器中所做的修改。这样可以保持与新的可编辑数量输入字段的兼容性，同时也保持与旧格式的兼容性。

具体修改如下：

1. 在`collectQuoteData`函数中，将第8593行的代码替换为：

```javascript
// 获取数量（处理输入框和文本两种情况）
let quantity = '';
const quantityInput = item.querySelector('.item-quantity');
if (quantityInput) {
    quantity = quantityInput.value;
} else {
    const quantityCell = item.querySelector('td:nth-child(4) div');
    if (quantityCell) {
        quantity = quantityCell.textContent;
    }
}
```

这样，函数会首先尝试从`item-quantity`输入字段中获取数量，如果找不到，则回退到从静态div中获取，保持与旧格式的兼容性。
