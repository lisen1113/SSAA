# PDF报价单布局优化和空白页修复计划

## 问题分析
1. **字体被拉长**：PDF生成时的缩放比例或布局问题导致字体变形
2. **排版松散**：公司信息和客户信息使用段落布局，间距过大
3. **空白页问题**：PDF生成时可能添加了不必要的空白页
4. **邮箱内容错误**：公司信息中的邮箱地址需要修改为提示文本
5. **页脚信息过多**：页脚显示的公司信息过多，只需要显示公司名称

## 解决方案

### 1. 修复字体拉长问题
- **调整html2canvas参数**：优化scale参数和渲染设置
- **修改PDF生成逻辑**：确保图片尺寸计算正确，避免拉伸
- **统一字体设置**：确保HTML和PDF中的字体一致

### 2. 优化公司信息和客户信息排版
- **使用表格布局**：将公司信息和客户信息改为表格布局，减少间距
- **调整间距**：减少段落间距和边距
- **优化字体大小**：适当调整字体大小，提高信息密度

### 3. 修复空白页问题
- **修改PDF生成逻辑**：检查每页内容是否为空
- **添加空白页检测**：在保存PDF前删除空白页
- **优化内容分割**：确保内容分割合理，避免产生空白页

### 4. 修改邮箱内容
- **更新公司信息**：将固定邮箱地址改为提示文本"销售自己填写，格式为：xx@yiheit.net"
- **统一格式**：确保两个导出功能使用相同的邮箱提示文本

### 5. 简化页脚信息
- **修改页脚HTML**：只保留公司名称，删除地址和电话信息
- **统一格式**：确保两个导出功能使用相同的页脚格式
