## 建立报价生成器中产品配置的对应关系

### 任务分析
根据用户要求，需要在报价生成器中建立产品类别、具体产品、处理器、NPU、屏幕尺寸、内存、存储、颜色的对应关系，确保每个选项里只出现该产品应有的选项，其他与该产品无关的配置选项不需显示。

### 具体修改步骤

1. **创建产品配置对应关系数据库**
   - 在JavaScript代码中创建一个新的对象，存储每个产品的具体配置选项
   - 基于产品知识库中的内容，为每个产品定义处理器、NPU、屏幕尺寸、内存、存储、颜色的选项

2. **修改产品选择变化时的处理代码**
   - 更新`productSelect.addEventListener('change', ...)`函数
   - 根据选中的产品，从配置对应关系数据库中获取相应的选项
   - 更新处理器、NPU、屏幕尺寸、内存、存储、颜色的下拉选项

3. **添加NPU选项处理**
   - 在HTML中添加NPU配置选项的下拉菜单
   - 在JavaScript中添加NPU选项的更新逻辑

4. **添加内存和存储选项处理**
   - 在JavaScript中添加内存和存储选项的更新逻辑
   - 根据选中的产品，显示对应的内存和存储选项

5. **验证配置选项的准确性**
   - 仔细核对产品知识库中的内容
   - 确保每个产品只显示其应有的配置选项

### 技术说明

#### 产品配置对应关系数据库结构
```javascript
const productConfigMap = {
  'surface-pro-snapdragon': {
    processors: ['Snapdragon X Plus'],
    npus: ['Qualcomm Hexagon (45 TOPS)'],
    screenSizes: ['12 英寸'],
    memories: ['16GB', '24GB'],
    storages: ['256GB (UFS)', '512GB (UFS)', '1TB (UFS)'],
    colors: ['亮铂金']
  },
  // 其他产品的配置...
};
```

#### 主要修改文件和函数
- **文件**: index.html
- **主要函数**: `setupQuoteFunctionality()` 中的产品选择变化处理函数

### 预期结果
- 当选择不同的产品时，处理器、NPU、屏幕尺寸、内存、存储、颜色的下拉选项会自动更新
- 每个选项里只出现该产品应有的选项，其他与该产品无关的配置选项不会显示
- 所有配置选项都基于产品知识库中的内容，确保准确性
