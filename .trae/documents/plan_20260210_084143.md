# 修复导出预览与导航菜单PDF导出不一致问题

## 问题分析
通过比较代码，我发现导出预览和导航菜单的PDF导出功能存在以下差异：

### 导航菜单导出 (exportBtn) 的 PDF 格式：
- 使用Word转换方式，先生成Word文档，然后提示用户使用Word转换为PDF
- 使用完整的HTML结构，包含详细的样式
- 表格有边框、居中对齐、自动换行
- 字体使用 SimSun，字体大小为 10pt
- 页边距为 12px，行高为 1.3
- 报价有效期为 7 天
- 报价单编号使用 quoteNumber 变量

### 导出预览 (exportPreviewBtn) 的 PDF 格式：
- 使用 html2canvas + jsPDF 生成真正的PDF文件
- 使用不同的HTML结构，字体为 Microsoft YaHei, SimSun, sans-serif
- 表格样式不同，文本左对齐
- 报价有效期为 30 天
- 报价单编号硬编码生成
- 没有详细的样式设置

## 修复方案
修改导出预览的 PDF 导出逻辑，使其与导航菜单的PDF导出功能完全一致：

1. **更新导出方式**：使用与导航菜单相同的Word转换方式
2. **统一HTML结构**：使用与导航菜单相同的完整HTML结构
3. **统一样式设置**：应用相同的CSS样式，包括字体、大小、边距、行高等
4. **统一数据处理**：确保报价有效期为 7 天，报价单编号使用 quoteNumber 变量
5. **统一表格样式**：确保表格有边框、居中对齐、自动换行等效果
6. **统一导出流程**：保持与导航菜单相同的导出流程和用户提示

## 具体修改点

**修改导出预览的 PDF 导出功能** (index.html:9897-10191)
- 替换现有的 html2canvas + jsPDF 生成方式
- 使用与导航菜单相同的Word转换方式
- 应用相同的HTML结构和CSS样式设置
- 确保报价有效期为 7 天
- 确保报价单编号使用 quoteNumber 变量
- 保持与导航菜单相同的表格样式和布局
- 添加相同的用户提示信息，指导用户使用Word转换为PDF

这样可以确保导出预览和导航菜单导出的PDF文档内容完全一致，满足用户的要求。
