## 更新报价生成器中添加产品到报价单的功能

### 任务分析
根据用户要求，需要在报价生成器中实现以下功能：
1. 当用户选择了对应产品和配置后，添加到报价单时自动填入对应的产品编码
2. 自动填入产品名称和配置内容（按照处理器、NPU、屏幕尺寸、内存、存储、颜色的顺序）
3. 首先更新Surface Pro 商用版, Windows 11 AI+ PC, 13 英寸 | Intel Core Ultra所对应的所有产品内容
4. 根据用户提供的产品编码、配置和ERP价格对应关系进行更新

### 具体修改步骤

1. **创建产品编码和价格对应关系数据库**
   - 基于用户提供的表格，创建一个新的JavaScript对象，存储Surface Pro 13英寸 Intel Core Ultra的产品编码、配置和ERP价格
   - 配置内容按照处理器、NPU、屏幕尺寸、内存、存储、颜色的顺序进行存储

2. **修改添加到报价单的代码**
   - 更新`addToQuoteBtn.addEventListener('click', ...)`函数
   - 获取用户选择的配置选项（处理器、NPU、屏幕尺寸、内存、存储、颜色）
   - 根据选择的产品和配置，从数据库中获取对应的产品编码和ERP价格
   - 生成配置内容字符串，按照要求的顺序排列
   - 更新报价项的HTML结构，填入正确的产品编码、产品名称和配置内容

3. **测试和验证**
   - 确保Surface Pro 13英寸 Intel Core Ultra的所有配置都能正确匹配对应的产品编码和价格
   - 验证配置内容的格式和顺序是否正确

### 技术说明

#### 产品编码和价格对应关系数据库结构
```javascript
const surfaceProIntelConfigMap = {
  'CU5/16/256/Black': {
    code: 'EP2-20081',
    price: 12088
  },
  'CU5/16/256/Platinum': {
    code: 'EP2-20098',
    price: 12088
  },
  // 其他配置...
};
```

#### 配置内容生成格式
```
处理器/NPU/屏幕尺寸/内存/存储/颜色
例如：CU5/Intel AI Boost (40 TOPS)/13 英寸/16GB/256GB SSD/Black
```

### 预期结果
- 当用户选择Surface Pro 13英寸 Intel Core Ultra及其配置后，点击"添加到报价单"按钮
- 系统自动填入对应的产品编码、产品名称和配置内容
- 配置内容按照处理器、NPU、屏幕尺寸、内存、存储、颜色的顺序显示
- 价格使用用户提供的ERP价格

### 后续扩展
- 后续可以按照相同的方式为其他产品创建对应的产品编码和价格数据库
